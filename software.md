# Software

Ham radio software and web services, grouped by what they do.

CW specific software (trainers, decoders) lives in [cw.md](cw.md).

## Logging — contest

| Name | What it is | Platform | Price | LoTW | Link |
|---|---|---|---|---|---|
| N1MM Logger+ | The most used contest logger. CW, SSB, RTTY, digital | Windows | Free | Via integrations | https://n1mmwp.hamdocs.com/ |
| DXLog.net | Contest logger. CW, SSB, digital | Windows | Paid | Via integrations | https://www.dxlog.net/ |
| Win-Test | Contest logger, strong for multi-operator | Windows | Paid | Via integrations | https://www.win-test.com/ |
| WriteLog | Contest logger. CW, SSB, RTTY, digital | Windows | Paid | Via integrations | https://writelog.com/ |
| QARTest | Contest logger. CW, SSB, digital | Windows | Free | Via integrations | https://www.ik3qar.it/software/qartest/en/ |
| TR4W | Light contest logger. CW, SSB | Windows | Free | Via integrations | https://tr4w.net/ |
