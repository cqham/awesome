# Awesome HAM

A collected list of ham radio resources.

## Contents

- [CW (Morse code)](cw.md) — devices, books, online trainers, translators, games, training software, decoders, clubs
- [Software](software.md) — logging, DX spotting, propagation, rig control
- [Tools](tools.md) — calculators, maps and other online tools

## Contributing

New links are welcome. The quickest way is to click the pencil icon on any list
file and propose the change — GitHub opens the Pull Request for you. If you
would rather not edit a file,
[suggest a link in an issue](https://github.com/cqham/awesome/issues/new/choose).

See [CONTRIBUTING.md](CONTRIBUTING.md) for the link format and the rules.
