# CW (Morse code)

Resources for learning, practicing and operating CW.

## Devices

- [HamHobby shop](https://hamhobby.odoo.com/shop) — keys, paddles and CW accessories

## Publications

- [ITU-R M.1677-1 — International Morse code](https://www.itu.int/dms_pubrec/itu-r/rec/m/R-REC-M.1677-1-200910-I!!PDF-E.pdf) — the official standard
- [The Art and Skill of Radio-Telegraphy (N0HFF)](https://www.n9bor.us/images/pdf/n0hff_3.pdf) — classic book by William Pierpont
- [Daily Morse Code 'Scales' Sending Warm Up (WR7Q)](https://cwops.org/wp-content/uploads/2022/03/Everyday-Send-Code-WR7Q-ver.-7.pdf) — warm up routine before you key, PDF ([web version](https://cwops.org/wp-content/uploads/2024/08/Everyday-Send-Code-Web.htm))
- [CWops additional practice material](https://cwops.org/additional-practice/) — curricula and drills from CW Academy
- [Poradnik CW — SP2MDS](https://xtreme69.nazwa.pl/sp2mds/Poradnik-cw-SP2MDS.pdf) — CW guide in Polish

## Online learn

- [LCWO](https://lcwo.net/) — Learn CW Online, the classic Koch method course
- [Morse Code World](http://morsecode.world/) — trainers, translator and listening practice
- [Morse Code World — custom trainer](https://morsecode.world/international/trainer/trainer.html) — build your own audio from any character set
- [Morse Code Ninja](https://morsecode.ninja/) — huge set of practice audio, words and phrases
- [Better-ICR](https://better-icr.herokuapp.com/) — adaptive instant character recognition drill
- [Morse Trainer](https://mashu.github.io/MorseTrainer/)
- [RealMorse (DJ0MZ)](https://dj0mz.darc.de/RealMorse/realmorse01.html)
- [Ben's Best Bent Wire](https://bensbestbentwire.com/)
- [Vail Morse](https://vailmorse.com/)
- [Code Groups Trainer](https://hamshacktech.com/cw-tools/code-groups-trainer/)
- [CW Checker](https://tools.hamradioduo.com/cw-checker/) — records your sending and tells you how clean it is
- [Morse Code Translator](https://morsecodeworld.org/) — text to Morse and back

## Games

Learning by playing. Good when drills get boring.

- [Morsle](https://morsle.fun/) — daily Morse puzzle
- [Morse Invaders](https://morseinvaders.com/tx/)
- [Morse Battleship](https://tools.hamradioduo.com/morse-battleship/)
- [Morse ATC](http://morseatc.s3-website.eu-central-1.amazonaws.com/)
- [Morse Walker](https://morsewalker.com/)

## Training software

- [Morse Runner](https://www.dxatlas.com/MorseRunner/) — contest simulator, the standard practice tool. Windows, free
- [Morse Runner (W7SST fork)](https://github.com/w7sst/MorseRunner/releases) — active fork with more contests and modes. Windows, free
- [RufzXP](https://rufzxp.net/) — callsign copying at rising speed, brutal but it works. Windows, free
- [Koch Morse Trainer](https://dm3mat.de/software/kochmorse) — Koch method trainer. Windows, free
- [Just Learn Morse Code](https://justlearnmorsecode.com/) — Koch and Farnsworth trainer. Windows, free
- [Morse Mania](https://www.dong.world/2020/05/morse-mania/) — 270 levels on your phone. [Android](https://play.google.com/store/apps/details?id=net.countrymania.morse) / [iOS](https://apps.apple.com/us/app/morse-mania-learn-morse-code/id1511042196), paid

## Decoders

- [CW Skimmer](https://www.dxatlas.com/CwSkimmer/) — decodes a whole band at once. Windows, paid
- [CwGet](https://www.dxsoft.com/en/products/cwget/) — CW decoder from the soundcard. Windows, free and paid versions

## On air practice and scores

- [Reverse Beacon Network](https://reversebeacon.net/) — skimmers worldwide report who hears your CQ, and at what speed
- [CW Club RBN Spotter](https://rbn.telegraphy.de/) — RBN filtered down to CW club members
- [3830 Scores](https://3830scores.com/) — report your CWT and other contest scores
